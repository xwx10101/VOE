# VOE

## 🐍🪜 لعبة السلم والثعبان

لعبة السلم والثعبان الكاملة موجودة في مجلد [`snakes-and-ladders/`](snakes-and-ladders/).

- **العب الآن محليًا:** افتح `snakes-and-ladders/index.html` في المتصفح، أو شغّل
  `python3 -m http.server 8000` داخل المجلد.
- **التفاصيل والقواعد:** راجع [`snakes-and-ladders/README.md`](snakes-and-ladders/README.md).
- **اللعب على الإنترنت:** الصفحة الرئيسية `index.html` تحوّل مباشرة إلى اللعبة،
  لذا يمكن تفعيل GitHub Pages من: `Settings → Pages → Source: Deploy from a branch`
  ثم اختيار الفرع `main` والمجلد `/ (root)`. سيصبح الرابط:
  `https://xwx10101.github.io/VOE/`
