# 🐍🪜 السلم والثعبان

لعبة **السلم والثعبان** الكلاسيكية — نسخة ويب عربية كاملة، تعمل مباشرة في المتصفح بدون أي تثبيت أو بناء (No build step).

![لعبة السلم والثعبان](https://img.shields.io/badge/HTML5-Canvas-ffb020?style=flat-square) ![بدون مكتبات](https://img.shields.io/badge/zero%20dependencies-2fd0a3?style=flat-square) ![اللغة](https://img.shields.io/badge/لغة-العربية-38bdf8?style=flat-square)

## ✨ المميزات

- 🎲 **نرد ثلاثي الأبعاد** مع رسوم متحركة للرمي.
- 👥 **٢ إلى ٤ لاعبين** مع إمكانية جعل أي لاعب (ما عدا الأول) **خصمًا آليًا**.
- 🪜 **٦ سلالم** ترفعك للأعلى و **٧ ثعابين** تُنزلك للوراء — مرسومة بالكامل بـ Canvas.
- 🐢 حركة قطعة **مربعًا بمربع**، مع انزلاق سلس عند صعود السلم أو لدغة الثعبان.
- 🏁 **قاعدة الوصول بالضبط**: من يتجاوز المربع ١٠٠ يبقى في مكانه.
- 🔁 **رمي ٦ يمنح دورًا إضافيًا**.
- 🔊 مؤثرات صوتية مولّدة (Web Audio) بدون أي ملفات صوتية.
- 💾 حفظ أسماء اللاعبين وإعدادات الصوت في `localStorage`.
- 📱 تصميم متجاوب (جوال / سطح مكتب) + دعم كامل للاتجاه RTL ولوحة المفاتيح (`مسافة` للرمي).
- ♿ احترام `prefers-reduced-motion` وتسميات ARIA للأزرار.

## 🚀 التشغيل

الأسهل: افتح `index.html` مباشرة في المتصفح.

أو شغّله عبر خادم محلي (مفيد للجوال داخل الشبكة):

```bash
cd snakes-and-ladders
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## 🎯 قواعد اللعب

| القاعدة | التفصيل |
| --- | --- |
| البداية | كل اللاعبين عند المربع **١**. |
| الحركة | حرّك قطعتك بعدد النقاط الظاهرة على النرد. |
| السلم | إذا توقفت أسفل سلم، انتقل مباشرة إلى أعلى المربع. |
| الثعبان | إذا توقفت على رأس ثعبان، انزل إلى نهاية ذيله. |
| الفوز | من يصل إلى المربع **١٠٠** بدقة أولًا يفوز. |

## 🗂️ بنية المشروع

```
snakes-and-ladders/
├── index.html      # الواجهة والبنية
├── style.css       # التصميم (RTL + متجاوب)

```

## 🌐 النشر على GitHub Pages

1. اذهب إلى `Settings → Pages`.
2. اختر **Source: Deploy from a branch**.
3. حدّد الفرع `main` والمجلد `/ (root)` ثم احفظ.

الصفحة الرئيسية في المستودع تحوّل تلقائيًا إلى اللعبة، فتصبح متاحة على:

`https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

> بديل: يمكنك نشر مجلد اللعبة وحده باستخدام GitHub Actions
> (Source: GitHub Actions + workflow يرفع `snakes-and-ladders` كـ artifact).
